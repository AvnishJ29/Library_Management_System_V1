# 📚 Library Management System V1

A web-based library management system built with Flask, SQLite, and HTML (Jinja templates). This project allows librarians to manage book records and users to issue or return books via a clean, role-based interface.

## 🔧 Features

- 🧑‍💼 Role-based authentication (Librarian and User)
- 📖 Book listing, issuing, and returning
- ➕ Add/remove books (Librarian)
- 👤 Register and login/logout
- 📅 Issue history tracking
- 🧼 Simple and intuitive UI using HTML and Bootstrap

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, Bootstrap (via Jinja2 templates)
- **Database**: SQLite
- **Authentication**: Flask-Login
